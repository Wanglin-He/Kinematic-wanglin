审核人

判定方法

资产载入 MuJoCo，摆到指定构型，读世界坐标和几何距离。全程位置层 （mj_forward，不步进、不涉及质量摩擦），不调用任何模型—— 只有查表、点积、计数、距离。页面上的渲染图在评分之后补的，改不了任何分数。

KF1 · 关节配置保真度 —— 9 条

一条关节声明说了七件事，逐件判；另加两条，因为有两类失败没有字段覆盖。

parent A(b*) = 沿 body_parentid 上溯的第一个已绑定部件，须等于声明的父件 type jnt_type[k] = μ(声明) dof_composition body_jntnum[b*] = 1 这个部件只挂一个关节 axis_semantic c = |â·û|，û = −g/|g| vertical: c ≥ cos15° horizontal: c ≤ sin15° axis_admits_motion 沿声明轴向推 δ = min(0.25·行程, 0.05) 后，与父件距离 d₁ ≥ −ε anchor on_edge_of: 轴线内嵌 = min(|min s|,|max s|)/(max s − min s) ≤ 0.15 through_center_of: |质心到轴线| / 部件自身对角线 ≤ 0.05 range_and_reference |模型行程 − 声明行程| / 声明行程 ≤ 0.02 rigid_follower 随动件须在主动件的「不跨越任何关节可达集」内 travel_scale 部件自身包围盒对角线 / 行程 ≥ 0.5 仅 slide，抓「有关节没实体」

KF2 · 机械耦合保真度 —— 4 条

不看几何，看模型自己的约束表。MuJoCo 的 eq_data 写成 q₁ = a₀ + a₁q₂ + …，与契约的依赖 = 系数 × 独立 + 偏移逐字段对应。

KF2 = mean_g 1[bound(g)] × 1[ max_q |残差| ≤ ε_g ] bound 等式图上找 独立端 → 依赖端 的最短链，链上每条都 active coefficient 沿链复合（斜率相乘、偏移累加），|ĉ−c|/|c| ≤ ε 且高次项 ≤ 1e−9 expected_dof 自由度总数 −（成员数 − active 图上的连通分量数）= 声明值 residual 33 个采样：中间关节按模型摆、依赖端按契约摆，读 efc_pos

KF3 · 可行运动一致性 —— 四层采样 + 3 条

把资产瞬移到上千个离散构型，每个 mj_forward 一次， 用 mj_geomDistance 量部件对之间的距离。不积分轨迹、不算接触力。

采样 ① 逐自由度 33 点 ② 成对 9×9（只对包围盒可能相交的） ③ 声明状态全组合 ④ Halton 填充 256×d 柜子 1,119 个构型（满网格 33³ = 35,937）；Halton 第 k 点是 k 的固定函数，无随机种子 forbidden_pair 该对通过 ⟺ 所有非豁免构型的最大穿透 ≤ 0.001 m；按对计分不按样本 required_contact 通过 ⟺ 该状态的构型里最近距离 ≤ 0.005 m state_reachability 通过 ⟺ 该状态的构型里所有禁止对穿透 ≤ 0.001 m

打分

score = 通过条数 / 不是 N/A 的条数 分母 = 0 → 记 None（不是 1.0 也不是 0.0） N/A = 工具评估不了这条声明（部件绑不上、关节无限位、slide 没有锚点…） 不计入分母，也不算通过

怎么审

  • 先读 prompt，明确这个物体本来该怎么动。
  • 看四张环绕图（0°/90°/180°/270°，参考姿态，统一中性灰）。
  • 再看下面的判负清单，写下你自己的判断。你写的不影响机器的分数，单独导出。
有些判负图上看不出来。几毫米的轴套互穿、「从没碰到该锁的东西」这类缺失， 以及只在中间构型出现的干涉（两个端点姿态都是干净的），四张静态图都显示不了——这时以数值为准。 判负也可能是契约写错而不是资产做错，看着不对就直接写下来。
